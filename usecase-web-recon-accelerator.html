The Web Recon Accelerator

Automatise la phase de tests en boîte noire des pentests web : tous les outils habituels exécutés automatiquement, analysés par un LLM local — sans jamais envoyer de donnée vers une API externe.

Workflow déterministe · pas un agent IA LLM 100% local +5h gagnées en moyenne / audit nmap · nuclei · testssl
01 · Le projet

Présentation du projet

Né dans la BT AIR, cet outil transforme l'étape de reconnaissance des pentests web — répétitive et chronophage — en un pipeline automatisé et reproductible.

Contexte

Les pentests web sont des missions récurrentes de la BT AIR, qui débutent par une étape de « boîte noire » : la reconnaissance, pour obtenir des informations sur l'application cible et identifier les premières vulnérabilités.

Cette étape s'appuie toujours sur les mêmes outils et ne nécessite généralement pas une grande expertise humaine — une bonne opportunité d'automatisation.

Objectifs

  • Automatiser l'étape de tests en boîte noire des tests d'intrusion web.
  • Libérer du temps auditeur pour les phases de test à plus forte valeur ajoutée.
  • Garantir la confidentialité totale des données clients : aucun appel à une API externe.

L'outil en une phrase

Auto-TI-Web (alias « Web Recon Accelerator ») exécute automatiquement, via un script Python, tous les outils habituellement utilisés par le pentester (nmap, nuclei, testssl…), puis s'appuie sur un LLM exécuté en local pour analyser leurs résultats.

⚠️ Ce n'est pas un agent IA autonome : le choix des outils et leurs paramètres restent entièrement déterministes, fixés par le script. Seule l'analyse des résultats est confiée au LLM.

Valeur apportée

Gain de temps estimé de 0,5 à 1 jour par mission de pentest web, sur un total de 5 à 7 jours.

02 · Sous le capot

Architecture de l'outil

Un pipeline en trois étapes : exécution déterministe des outils, analyse par un LLM local, puis génération automatique du rapport Wavestone.

L'auditeur renseigne l'URL de l'application cible et la langue du rapport souhaitée. Le workflow retourne un rapport au format Markdown, prêt à être converti en rapport Word Wavestone via WReport, le moteur de génération de rapports existant de la BT AIR.

Bénéfices constatés

Gain opérationnel mesuré

Sur un pentest web type, l'outil déplace l'effort du temps auditeur vers du temps d'exécution automatisée : ~5h gagnées en moyenne par audit, soit 0,5 à 1 jour sur une mission de 5 à 7 jours.

Confidentialité

Zéro donnée envoyée à l'extérieur

Contrainte SMSI oblige : le LLM tourne en local sur le poste de l'auditeur, via Ollama.

  • Aucun appel à une API externe
  • Compatible avec les contraintes de confidentialité client
  • Exécution reproductible via Docker
Points de vigilance

Un outil, pas un agent autonome

Le choix des outils et de leurs paramètres reste manuel et déterministe : l'outil accélère l'exécution et l'analyse, il ne remplace pas le jugement de l'auditeur sur la stratégie de test.

  • Reste un outil d'accélération, pas un agent autonome
  • Vérification humaine des résultats avant livraison

* Retours basés sur l'utilisation réelle de l'outil lors de missions de pentest web menées par la BT AIR.
