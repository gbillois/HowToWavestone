Utiliser VS Code avec M365

Installer l’extension CoPro dans Visual Studio Code à partir d’un fichier VSIX, puis coder avec un agent qui s’appuie sur ton compte Microsoft 365. Suis le déroulé, coche chaque étape.

# sans droits admin # installation VSIX # ~10 min # VS Code · CoPro · M365

Astuce : déroule la page de haut en bas. Clique sur les numéros pour cocher les étapes validées et sur copier pour récupérer un prompt. Le sélecteur de langue est en haut à droite.

Le concept

Trois briques, et c’est tout

Un éditeur, une extension installée à la main, un compte M365. Comprends ces trois briques et l’installation devient mécanique.

Étape 1 — Installer

Installer l’extension CoPro

À faire une seule fois. Aucun droit admin nécessaire. Comptez 10 min.
0/5 étapes
1

Installer Visual Studio Code

Si ce n’est pas déjà fait, télécharge VS Code pour Windows et installe-le (version utilisateur, sans droits admin).
code.visualstudio.com ↗
2

Récupérer le fichier VSIX de CoPro

Demande le fichier .vsix de CoPro à l’équipe CYB AI Maker et enregistre-le sur ton poste (par exemple dans Documents). Note bien le chemin : tu en auras besoin à l’étape 4.
3

Ouvrir le panneau Extensions

Dans VS Code, ouvre la vue des extensions :
  1. Menu View (Affichage) → Extensions
  2. Ou le raccourci Ctrl+Shift+X
  3. Le panneau Extensions s’affiche dans la barre latérale
4

Install from VSIX

L’installation manuelle se fait depuis le menu « ... » en haut du panneau Extensions :
  1. Clique sur ... (Views and More Actions) en haut à droite du panneau Extensions
  2. Choisis Install from VSIX...
  3. Sélectionne le fichier .vsix de CoPro récupéré à l’étape 2, puis Install
  4. Recharge la fenêtre si VS Code le propose (Restart Extensions / Reload Window)
Variante

Le même résultat s’obtient depuis la palette de commandes : Ctrl+Shift+P → Extensions: Install from VSIX...

5

Vérifier et se connecter

Dans le panneau Extensions, section Installed, vérifie que CoPro apparaît bien. Ouvre ensuite le panneau CoPro et connecte-toi avec ton compte Microsoft 365 Wavestone.
Étape 2 — Utiliser

Ton premier échange avec CoPro

Ouvre un dossier de travail dans VS Code (File → Open Folder), puis formule ta demande dans le panneau CoPro. Deux prompts pour démarrer :

Exemple — découvrir le dossier
Analyse le dossier ouvert et explique-moi en dix lignes à quoi sert chaque fichier.
Exemple — première page
Crée-moi une page HTML autonome nommée demo.html qui affiche un tableau de bord simple avec trois indicateurs.
Human in the loop

CoPro travaille sur les fichiers du dossier ouvert et te montre ce qu’il modifie. Relis les changements proposés avant de les valider — rien ne part en production tout seul.

Données & confidentialité

Comme pour tout agent CYB : pas de données client sensibles dans un dossier de travail sans validation, et un budget d’usage cadré. En cas de doute, reporte-toi aux principes de conception des agents.

L’installation a échoué ?

Vérifie que le fichier .vsix n’est pas bloqué par Windows (clic droit → Propriétés → Débloquer) et qu’il est bien enregistré en local, pas sur un lecteur réseau.

Mettre à jour CoPro

Une extension installée par VSIX ne se met pas à jour automatiquement. Pour une nouvelle version, récupère le nouveau fichier et refais l’étape Install from VSIX.

Toujours un dossier dédié

Ouvre un dossier par projet. L’agent ne voit que ce dossier : c’est la façon la plus simple de maîtriser ce que tu lui donnes à lire.
