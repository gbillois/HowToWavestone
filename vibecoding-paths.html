Vous voulez vibecoder un premier agent sans savoir quelle méthode suivre ? Nous voyons deux grandes approches, comparées ici question par question. Alors, plutôt team « Exploration personnelle » ou « Communauté AI Makers for CYB » ?

AI Makers

Le parcours AI Makers

Le schéma ci-dessous déroule le parcours AI Makers étape par étape, de la préparation du poste jusqu’à l’usage en mission. Lancez la lecture ou cliquez sur une étape.

Lancez la lecture pour dérouler le parcours. Un collaborateur souhaite développer un agent IA selon la méthode AI Makers for CYB. Il commence par préparer son environnement de développement : VS Code, l’extension Claude Code et Git. Ensuite, il se rend sur Parallax et demande un environnement d’hébergement et d’exposition pour son futur agent IA. De manière automatisée, Parallax crée deux espaces dédiés au futur agent IA : un dépôt de code sur le GitLab Wavestone et un espace de stockage S3 sur un compte AWS également géré par Wavestone. Des automatisations détectent les modifications apportées au code et mettent à jour les fichiers finaux stockés sur AWS S3. L’agent IA développé est ainsi automatiquement mis à jour. Pour accéder à son agent IA, nouvellement créé et exposé sur internet, le collaborateur doit s’authentifier via le SSO Wavestone. Une fois le collaborateur authentifié, l’accès à son agent est accordé. Selon les besoins, le collaborateur peut demander une instance Azure Foundry et brancher son agent IA à des modèles LLM hébergés sur le tenant Azure Wavestone, afin d’utiliser des données client dans le respect des principes de confidentialité.

Exploration personnelle AI Makers for CYB
Point de départ Mon premier agent
01
Exploration personnelle

Vous ouvrez un outil d’IA et vous itérez tout de suite, sans prérequis. C’est le parcours le plus rapide pour démarrer.

01

Quelles méthodologies existent pour vibecoder mon premier agent IA ?

Communauté AI Makers for CYB

Vous suivez les pratiques et les outils de la communauté. Le démarrage demande un peu plus de préparation, mais le cadre technique et les règles sont déjà en place.

Pour tester une idée rapidement, l’exploration personnelle suffit.

02
Exploration personnelle

N’importe quel logiciel ou site web, comme ChatGPT. L’objectif est de produire un PoC pour tester votre idée.

02

Quels logiciels de développement utiliser ?

Communauté AI Makers for CYB

VS Code et l’extension Claude Code, validés par la DSI Wavestone. Le code produit peut être repris et maintenu par d’autres makers.

Si l’agent doit être maintenu dans le temps, le parcours communauté est plus adapté.

03
Exploration personnelle

Une plateforme gratuite de type GitHub, non gérée par Wavestone. Vous êtes seul responsable du code et de sa sécurité.

03

Où stocker le code source de mon agent ?

Communauté AI Makers for CYB

L’instance GitLab interne, administrée et sécurisée par Wavestone. Les makers peuvent y collaborer pour faire évoluer et maintenir l’agent.

04
Exploration personnelle

Exposition sur une plateforme d’hébergement de type GitHub Pages, Vercel, Netlify ou Cloudflare Pages.

04

Comment rendre mon agent disponible en ligne ?

Communauté AI Makers for CYB

Parallax, un espace d’hébergement sécurisé géré par Wavestone. L’agent est accessible via le SSO Wavestone et mis à jour automatiquement à chaque push.

Pour un agent accessible aux seuls collaborateurs Wavestone, passez par Parallax.

05
Exploration personnelleDonnées client interdites

N’importe quel modèle disponible en ligne, au choix. Utilisez uniquement des données fictives ou des contenus internes, jamais de données client.

Alerte - donnée client Aucune utilisation de données de clients dans l’exploration personnelle.

Les données client ne sont autorisées que dans le parcours AI Makers for CYB.

05

À quels modèles LLM puis-je brancher mon agent IA ?

Communauté AI Makers for CYB

Les modèles du tenant Azure Foundry Wavestone, hébergés en Europe et validés par la DSI Wavestone. Les frais d’appels sont pris en charge et suivis (FinOps). L’agent peut être utilisé en mission, avec des données client.

Pour des données client, seul le tenant Azure Foundry Wavestone est autorisé.
